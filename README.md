# Atelier Desmarchelier – Le Canu

Site vitrine bilingue français / anglais de l'atelier de lutherie et d'archèterie à Lille.

Site : https://aristophane.github.io/LeCanu/

## Modifier et publier

Le site statique est dans `dist/`. Toutes les images et polices sont locales et les liens vers les ressources sont relatifs pour fonctionner sous `/LeCanu/`.

Chaque push sur `main` déclenche `.github/workflows/pages.yml`. Le workflow vérifie la syntaxe JavaScript et publie uniquement `dist/` sur GitHub Pages.

Pour l'aperçu local : `npm run dev`, puis http://127.0.0.1:4187.
Vérification : `npm run check`.

## Fonctionnalités

Navigation mobile, version FR/EN, présentation de l'atelier et des deux métiers, prestations dépliables, galerie filtrable et agrandissement, appel téléphonique, itinéraire et préparation d'un e-mail. Le formulaire ne confirme aucun rendez-vous et ne transmet rien depuis un serveur : le visiteur doit envoyer son message depuis sa messagerie.

## Informations éditoriales

Le site utilise les photographies et le brief fournis pour le projet. La plaque photographiée et la présentation de l'atelier identifient Juliette Desmarchelier, luthière, et Yannick Le Canu, archetier. Les autres identités et les titres MOF non confirmés du brief ont été écartés.

L'adresse 7 rue d'Ostende à Lille, le téléphone et l'e-mail sont issus de la présentation de l'atelier : https://runinclub.fr/wp-content/uploads/2019/02/Atelier-Desmarchelier.pdf. Les horaires divergent selon les sources ; le site recommande d'appeler. Les coordonnées actuelles et les informations légales complètes restent à confirmer par l'artisan.

Les photographies sont une présentation de l'atelier, pas un inventaire de stock. Aucun cookie publicitaire ni outil de mesure d'audience n'est utilisé.
